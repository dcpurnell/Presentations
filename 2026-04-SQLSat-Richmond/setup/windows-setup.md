# Windows Setup

For Windows setup instructions (Chocolatey + native SQL Server install), refer to Anthony Nocentino and Ben Weissman's companion repository:

**[github.com/bweissman/code - SQL 2025 / Anthony and Ben](https://github.com/bweissman/code/tree/master/SQL%202025/Anthony%20and%20Ben)**

Their repo includes:

- SQL Server 2025 installation via ISO
- Chocolatey-based tool installation (Ollama, OpenSSL, nginx)
- nginx reverse proxy configuration for HTTPS
- Self-signed certificate generation
- Ollama model setup and testing
